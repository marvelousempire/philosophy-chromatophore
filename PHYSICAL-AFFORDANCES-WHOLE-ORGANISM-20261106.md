# Physical Affordances as Whole-Organism Behavior — Kokonut UI Study

## Scope
Chromatophore remains the philosophy of the **whole coherent adaptive software organism**: becoming, identity, meaning, form, behavior, function, computation, permission, operation, evidence and continuity. A physical-feeling UI is **one expression**, not the definition of Chromatophore. Preserve octopus, nonagon, Morph Law, Optimus Instant, and BEHAVIOR-FIRST-CLASS.md.

- This is **design/source guidance**, not an installed library, a commissioned ACT V5, or permission to execute a transaction.

## Contract
A physical metaphor becomes a coherent behavior only when it binds **stable node ID → user intent → sensed trigger → conditions → owner authority → deterministic state transition → visual/haptic/audio feedback → real effect (if authorized) → independent receipt → retained work/Return**.

| Lens from BEHAVIOR-FIRST-CLASS | Physical example | Required distinction |
|---|---|---|
| Reaction | Pull cord or slide thumb | Gesture is input, not authorization |
| State | Dial notch or lamp on/off | Client optimism vs authoritative owner state |
| Transformation | Tear ticket, spring text, morphing card | Surface changes, identity remains |
| Navigation | Receipt opens its review detail | Focus, route and Return persist |
| Calculation | Activity rings exceed 100%; terrain rises | Exact underlying values and units remain readable |
| Communication | Client sends requested command | Request/ACK is not durable owner proof |
| Adaptation | Reduced motion, touch, keyboard, native Swift | Meaning survives different input modalities |
| Persistence | Saved setting or approved transaction | Independent readback and continuity after restart |

## Nonagon expression (not a new mandatory nine-part engine)
The eight surrounding nodes may carry trigger, condition, action, state, feedback, owner, evidence and continuity; the center fuses them into one coherent interaction. This is an illustrative mapping, not a claim that the nine-position geometry is only for UI. Rebind, never teleport: if a lamp switch changes appearance, preserve its owner, work identity, permission and actual on/off state. A physical animation may run locally while the operation is pending; failure must restore truthful state and offer recovery.

## Two-sided proof
1. **Sensory:** pointer/touch/keyboard feel, discrete detents, focus, motion bounds, reduced-motion alternative, accessibility and clear state.
2. **Functional:** actor, authorization, source, owner result, idempotent receipt, denial, retry, independent readback and same-work Return.

**A torn ticket is not a payment receipt. A completed slide is not approval. A glowing lamp is not proof that a protected device switched.** Niece One directs form, Nephew One function, Automata governs qualified work, and ACT V5 displays the coherent result when commissioned. Do not create parallel renderers, identity stores or permission engines.
