# StubTHAT — Animal research record and handoff

This is an indexed **source stub library**, **not** the StubTHAT runtime. Preserve specialist ownership and truth.

## Required record for each animal
- **Stable animal ID** and canonical name; exact species when known.
- **Founder source** and whether the animal was explicitly discussed or later suggested.
- **Physical mechanism**, biological timing, reversible vs developmental.
- **Optical factors:** light, object geometry, viewing direction and visual reception.
- **Evidence source** (URL, authors, date) and species applicability.
- **Function candidate:** what a proposed Chromatophore program could do.
- **Form candidate:** what visible or interactive expression is intended.
- **Unresolved questions / ambiguity holds**, including terminology.
- **Owner, lineage, required approval and version**.
- **Test, expected vs actual result and independent witness**, or explicit **NOT_TESTED**.

## Suggested progression — not an installed workflow

Research stub → biological source verification → Constructive Reasoning → intent/concept → Function and Form → House of Cards → qualified MakeWAY plan → MicroSlice test → independent evidence.

Do not turn a biological source into a code execution order without an authorized, measurable requirement. If a proposed program needs an execution language, the five-language real-hardware benchmark gate still applies.

This catalog is rooted in the existing Chromatophore philosophy; it does not relocate the official StubTHAT application or override its source.
