# Chromatophore: Whole-Organism Doctrine

Chromatophore is the governing philosophy of the entire coherent, adaptive software organism. It includes a node's birth and identity, its meaning, structure, data, form, behavior, function, computation, interaction, operation, authority, evidence, and continuity. It is not a frontend, a backend, a user interface, a user experience, an animation library, an engine, or merely an integration between those parts.

Every visible and invisible capability is an expression of the same whole. The Actor Profile records becoming, the octopus supplies the model of coordinated parts, the nonagon supplies a nine-position stamp and fusion point, Morph Law supplies rebinding, and Optimus Instant supplies the ambition of responsive continuity. These do not divide the organism into independent philosophies.

The founder's Hairline comparison is about making a philosophy into actual interactive, executable experience. Hairline demonstrates one smaller example of that. Chromatophore aims to apply its unified philosophy to the whole system, including real functions and accountable effects, without claiming that Hairline already implements that wider scope.

An implementation must preserve identity, intent, source, meaning, permission, relevant work state and recovery while transforming expression or permitted behavior. A changing visual must not be mistaken for an authorized effect. A prototype must not be mistaken for a commissioned runtime.

**Interpretation test:** Any explanation reducible to 'Chromatophore is a UI feature', 'Chromatophore is a backend engine', or 'Chromatophore joins frontend and backend' is incorrect. Begin with the entire organism, and describe any particular example as one expression of it.

The founder's original documentation remains authoritative historical material. This clarification preserves its nuances rather than replacing or subtracting them.
