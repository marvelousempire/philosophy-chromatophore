# 003 — Domain adoption: philosophy-chromatophore

## Purpose

**Whole-software-organism philosophy.** Preserve identity, meaning, authorization, behavior, form, function, state and evidence; never reduce this doctrine to a UI effect.

## Smallest acceptance scenario

A canvas changes form without losing its drafts or permissions; actual actions are verified separately.

## Required receipt

Document repo and revision, host/device, action attempted, result observed, relevant DYM rule decision and what remains. If only writing was committed, report **documentation proposed, no runtime acceptance**.

## Boundary

This overlay cannot replace a canonical owner document, reassign Gitea authority, change installed services, bypass approvals or silently amend the official nine-entry Optimus Nephew philosophy catalog. Disagreements must be surfaced for an authorized decision.
