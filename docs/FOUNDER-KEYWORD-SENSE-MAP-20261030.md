## What the word relationships reveal (interpretation, not a new invention)

The *kernel / semantic / node / token / variable / placeholder* group probes a **stable core of meaning and reference with replaceable bound values**. The *instant / binary / dynamic / modularity* group probes **how quickly and lawfully states change**. The *chromatophore / nonagon / octopus / pixel / form / Morph Law / rebind* group probes **how those states become visible, arranged and transformed**. The *Primary Intent / EGG / actor profile* group probes **how identity, purpose and lineage survive those changes**.

These groups are **not synonym lists**. Synonymy is a claim about a particular *sense*. A token can point to an EGG; it is not automatically the same thing. A placeholder can hold a variable binding; it is not necessarily a node. A zero/one decision is not identical to a compiled binary. A kernel can mean the OS kernel, a compute kernel, or a bounded conceptual/application core; in this study the proposed meaning is the latter, specifically a *semantic operating kernel*, while executable scope remains open.

### Why the founder's question matters

Instead of choosing an implementation tool first, the keywords expose recurring design invariants: **preserve identity and intent, allow bounded rebinding, maintain continuity and truth, reuse existing owners, and make changed form perceptible without losing the work**. This helps contributors recognize what the founder is trying to build while retaining unresolved questions rather than manufacturing answers.
